description: Draft the weekly Canvas announcement with the coming week's class materials.
---

1. Call `get_week_materials` (with the date the TA gives, or none for next week).
2. Write a short announcement: each session's date and topic, slide links, readings and
   anything due. Use only what the tool returned.
3. If anything is missing, do not make it up or leave a placeholder link. List it under
   `beforePosting` and say "coming soon" in the body.
4. Call `draft_canvas_post`. Tell the TA it is a draft to review and post.

---
description: Work out who was not seen in a class session from attendance photos and the roster.
---

1. Read each photo and list visible name tags exactly as written. Count people with no readable tag.
2. Call `check_attendance` with the roster file and every name you read.
3. Reply with, in this order: names to decide (with candidates), the not-seen list, and the
   count of people with no readable tag. Then give the number present.
4. After the person decides, repeat the final list and ask them to confirm it.
